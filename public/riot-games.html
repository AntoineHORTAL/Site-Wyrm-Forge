For Riot Games — product key review

What's actually in Wyrm Forge, right now

Wyrm Forge is a companion site and desktop overlay for League of Legends. This page is a detailed, feature-by-feature snapshot of the product for anyone reviewing our production API key request: what's exclusive to the site, what's exclusive to the app, what's shared, what's built but not live yet, what we're actively working on, what's designed but not started, and what's still just an idea.

Compliance capability

Every feature can be switched off centrally, immediately

We built a single rollout system that controls both the site and the app from one internal dashboard. It was originally built to launch new features safely, but it doubles as a kill switch: almost every feature on this page — including every individual block of the overlay listed under "Exclusive to the app" (the live game panel, the comeback tracker, the build assistant, the damage overlay, the live matchup panel, jungle pathing, item set export, rune page apply, the community workshop, and so on) — has its own separate switch, added specifically so any one of them can be disabled without touching the others or shipping a new build.

  • No deploy needed — toggled from an admin dashboard, not a code change.
  • Fast to apply — the site checks for changes every 60 seconds; the app keeps a local cache and re-checks on its own schedule.
  • Accountable — disabling a feature requires typing a reason first; there's no silent toggle.
  • Granular, block by block — every overlay panel is its own independent switch, so we can turn off one specific block (say, just the build assistant, or just item set export) while every other panel keeps working normally.
Website only — wyrm-forge.com

Exclusive to the site

Runs in the browser. Nothing here touches the game client directly.

  • Public site & dashboardMarketing pages plus a signed-in player dashboard, both fully translated into French and English.
  • Player & match searchLook up any summoner by name and browse their recent match history, no app install required.
  • Match detail pagesA dedicated deep-dive page per match, with a full stat and matchup breakdown for that game (part of the wider MatchUp system — see "Shared" below).
  • Patch notes pageA page summarizing official Riot patch notes, generated with AI assistance and kept French-only by choice.
  • Free champion rotationShows this week's free-to-play champion rotation on the dashboard, refreshed automatically from Riot's data.
  • Subscription & billingPricing page, checkout, and card payments through Stripe. Upgrades and downgrades happen here; the app only reads the result.
  • Ads on the free tierBanner ads shown only to free-tier ("Apprentice") players inside their dashboard, served through Google AdSense. Never on the public marketing pages, never for paying players.
  • Admin dashboardInternal-only tool, not visible to players: managing user accounts, editing patch notes content, and switching features on or off through the rollout system, organized into several tabs.
  • Subscription self-serviceA player can cancel their subscription or update their payment card directly from their dashboard, through Stripe's customer portal, without contacting us.
Desktop app only — Windows overlay

Exclusive to the app

Runs alongside the League client while a game is live. Every overlay feature we currently have is listed below.

Live overlay panels

  • In-game overlayThe base transparent window drawn over the League client, reading live stats, gold, items and cooldowns from Riot's Live Client Data API.
  • Live game panelAn overview of all 10 players in the current game (ranks, recent form), in the spirit of tools like Porofessor.gg.
  • Comeback trackerReads gold, objective and kill differentials as the game evolves and shows whether a team is pulling ahead, falling behind, or the game is close.
  • Build assistantAn AI-assisted suggestion for the next item purchase, based on the current game state and gold available. Internally nicknamed "Chaleur de la Forge."
  • Damage overlayA panel showing damage dealt and taken during the game.
  • Live matchup panelThe in-game half of the MatchUp system: tips about your lane opponent shown while you're actually playing (see "Shared" below for the site half).
  • Sidebar navigationLets a player switch between all of the panels above without leaving the overlay.

Jungle & minimap

  • Jungle pathing on the minimapA suggested jungle route drawn directly on the in-game minimap.
  • Automatic minimap calibrationDetects the player's resolution and minimap scale automatically, so the pathing overlay lines up correctly without manual setup.

Builds, items & runes

  • Item set exportExports a build directly into League's own item-set format, so it shows up as a quick-buy option in the in-game shop.
  • Rune page applyApplies a chosen rune page straight into the League client with one click, instead of setting it up manually.
  • Community workshopBrowse builds and jungle paths shared publicly by other players, from inside the app.

After the game & app upkeep

  • Post-game summaryA recap screen shown right after the game ends, before returning to the client lobby.
  • Automatic updatesThe app checks for and installs new versions itself on launch. Old installer files are cleaned up automatically in the background to avoid piling up disk space.
Both surfaces

Shared between site and app

Systems that exist once but are read, shown, or applied on both surfaces.

  • Staged rollout & kill switchesSee the callout at the top of this page — this is the system behind it.
  • MatchUpOne matchup system with two faces: a detailed breakdown on the site's match pages, and a live version shown in the app's overlay during the game itself.
  • Subscription tiersWhat a player pays for on the site determines what they get in the app — one account, one entitlement, checked by both surfaces automatically.
  • Bilingual interfaceBoth the site and the app ship in French and English from the same hand-maintained translation files. A few things are deliberately left French-only, like League rank names.
Coded and tested, switched off

Built, not live yet

Finished, but kept behind the rollout system above so nothing new appears until it's ready for everyone at once.

  • Launch featuresAn in-app currency, seasonal challenges, and daily quests are coded and tested, waiting for the switch. Meant to go live together as one launch moment.
  • Minimap click-through refinementA fix improving exactly which parts of the minimap overlay let mouse clicks pass through to the game underneath, rather than being intercepted. Built and unit-tested; still needs one validation pass in a real match before it ships.
  • Feature suggestion box & monthly voteLogged-in players will be able to submit a detailed feature request (title, description, category) from a new dashboard tab. Submissions stay private, visible only to their author, until a monthly voting round opens — at which point a shortlisted set becomes visible for players to vote on, with the author's identity never revealed even during voting. Fully built and tested, including an admin tool to open and close voting rounds, but held behind its own launch switch: it introduces a new kind of personal data (submitted ideas and votes tied to an account), so it's waiting on a privacy-policy update covering that before it opens.
  • Personal coaching packs (first phase)A player can submit a request for a tailored champion/role kit, which we then track internally as a case file. Booking is currently just an external link, and the kit itself is still put together and delivered by hand — the request submission and internal tracking are what's actually coded and held behind a launch switch. The live in-game coaching session is a separate, later step, still in the "thought through, not started" stage below.
Being worked on right now

In progress

Active work this month, mostly compliance-driven groundwork ahead of the features below.

  • Required billing emailsTransactional emails are being wired back in to cover three obligations under French consumer law: order confirmation, cancellation confirmation, and a reminder before an annual subscription renews.
Designed, no code yet

Thought through, not started

The mechanics, pricing, and edge cases are worked out; nothing has been built.

  • Personal coaching packs (live session)The final step of the coaching flow: 1-2 games played with a coach watching live to put the tailored kit into practice. The booking and kit-delivery steps are already built (see "Built, not live yet" above); this live-session step is designed but not coded.
  • Clans & guildsA free tier open to everyone and larger paid tiers for bigger groups, each with a ranking based on members' win rate, a search page, join requests reviewed by the group's leader, and a moderation process for reported groups. Fully specified, not coded.
  • "Legion" planA subscription shared by a group of five accounts, with one paying account inviting the other four. The structure is designed; today it exists only as a placeholder value in the database, with no real functionality behind it yet.
  • TournamentsA daily-to-monthly-to-annual structure was designed, but after legal review we confirmed that paid entry with cash prizes isn't viable under French law. Any version we eventually build would use cosmetic-only rewards (badges, profile borders) instead — not scheduled.
Discussed, not fleshed out

Just an idea

Come up in conversation, with no design work done and no timeline.

  • Match outcome predictionAn estimate of a game's odds while it's in progress. Mentioned as a possible future feature, no design done.
  • Video / replay analysisReviewing a recorded game rather than a live one. Mentioned as a "someday" feature; not designed or scheduled.
  • Windowed-mode support in the appThe overlay currently assumes the game always fills the whole primary screen. Supporting a windowed game client would need real design work; identified as a gap, not yet planned.
  • Beyond League of LegendsA long-term idea to support other Riot titles, starting with Teamfight Tactics, then possibly other games entirely. No timeline attached.
